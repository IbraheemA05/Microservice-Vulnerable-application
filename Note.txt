To define the user db :
        db.runCommand({
  collMod: "users",
  validator: {
    $jsonSchema: {
      bsonType: "object",
      required: ["userId", "username", "email", "password"],
      additionalProperties: false,
      properties: {
        _id: {},
        userId: { bsonType: "string" },
        username: { bsonType: "string" },
        email: { bsonType: "string" },
        password: { bsonType: "string" }
      }
    }
  },
  validationLevel: "strict",
  validationAction: "error"
})

Add indexing to the user db :
        db.users.createIndex({ userId: 1 }, { unique: true })
db.users.createIndex({ username: 1 }, { unique: true })
db.users.createIndex({ email: 1 }, { unique: true })


For the settings db :
    db.createCollection("settings", {
  validator: {
    $jsonSchema: {
      bsonType: "object",
      required: ["userId", "preferences", "notifications", "privacy", "createdAt", "updatedAt"],
      additionalProperties: false,
      properties: {
        _id: {},
        userId: {
          bsonType: "string",
          description: "Foreign key to auth.users.userId"
        },

        preferences: {
          bsonType: "object",
          required: ["theme", "language", "timezone"],
          additionalProperties: false,
          properties: {
            theme: {
              enum: ["light", "dark"]
            },
            language: {
              bsonType: "string"
            },
            timezone: {
              bsonType: "string"
            }
          }
        },

        notifications: {
          bsonType: "object",
          required: ["email"],
          additionalProperties: false,
          properties: {
            email: {
              bsonType: "bool"
            }
          }
        },

        privacy: {
          bsonType: "object",
          required: ["profileVisible", "searchIndexing"],
          additionalProperties: false,
          properties: {
            profileVisible: {
              bsonType: "bool"
            },
            searchIndexing: {
              bsonType: "bool"
            }
          }
        },

        createdAt: {
          bsonType: "date"
        },
        updatedAt: {
          bsonType: "date"
        }
      }
    }
  },
  validationLevel: "strict",
  validationAction: "error"
})

For dumping db in mongo
    mongodump --uri="mongodb://localhost:27017/your_db_name" --out ./dump

For restoring db in mongo
    mongorestore --uri="mongodb://localhost:27017/your_db_name" ./dump/
